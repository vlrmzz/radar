this week

Google announced Gemini 4 Carbon to a small set of partners, while Mistral and NVIDIA put out large open-weight models for text and speech.

  • Google announces Gemini 4 Carbon, its new top model

    Google calls Gemini 4 Carbon its strongest model, built for long, multi-step coding and security work. It is not broadly available yet. Access starts with a group of cyber defenders and widens to trusted partners, with developers and consumers to follow later. Google lists introductory pricing of $2 per million input tokens and $10 per million output tokens.

  • Mistral Large 4 is a 1-trillion-parameter open-weight model

    Mistral Large 4 is Mistral's largest open-weight model, a mixture-of-experts design (only a few parts of the model run for each token). It takes text and images, handles very long inputs and supports many languages, including all official EU languages. The license allows commercial use, but running it as a hosted service needs a separate agreement with Mistral. The model card lists vLLM, SGLang, Transformers and llama.cpp as ways to run it.

  • NVIDIA releases an open speech model that transcribes in 40 languages

    Nemotron-3.5-Transcribe is an open-weight model that turns speech into text and can also translate speech, label who is speaking and answer questions about audio. It covers 40 languages and accepts recordings up to one hour. The model card lists a license that permits commercial use.

how this page is made

A Claude Code job runs every Monday. A script collects the numbers: Wikipedia page views from Wikimedia, weekly installs from pypistats.org and the npm registry, stars and releases from GitHub, trending models and papers from Hugging Face, and the top AI stories on Hacker News. The agent never writes a number. It picks what mattered this week and writes the notes. A second agent checks each note against its sources and drops anything it can't confirm. A last script checks that every number in the notes matches the data and that every link works, and the page is published only if all of that passes. It has run 4 times so far: 4 published. The last run, on 2 Nov, published.

Page views measure curiosity, not use, and install counts include CI and mirrors, so read both as trends, not user counts. Raw data for this week
