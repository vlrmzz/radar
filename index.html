this week

DeepSeek added a web search API for agents, a compact open multimodal model trended, and installs of the MCP software kits kept growing.

  • DeepSeek adds search and page-fetch APIs for AI agents

    DeepSeek published two web APIs: one returns search results from its own search engine, the other turns a web page into Markdown text. They are meant for agents and apps that need live web content. The docs say failed, empty or timed-out requests are not charged. The announcement drew 566 points on Hacker News.

    Hacker News points566
    566 points on Hacker News DeepSeek search and fetch docs

  • MiniCPM-V 4.7, a compact open multimodal model, is trending

    OpenBMB's MiniCPM-V 4.7 is an open model that reads images and video. It has 35 billion parameters in total; the 'A3B' in its name means about 3 billion are active for each token (a mixture-of-experts design), which keeps it light enough to run on phones. It is released under the Apache-2.0 license and ranks #2 on Hugging Face trending.

  • Installs of the MCP software kits rise

    MCP (Model Context Protocol) is a standard way for AI apps to connect to outside tools and data. Installs of the TypeScript SDK grew 28% and the Python SDK 14%, level with FastMCP at 14%. The TypeScript SDK shipped 1.32.0 on 2 October, which limits when its HTTP client follows redirects.

how this page is made

A Claude Code job runs every Monday. A script collects the numbers: Wikipedia page views from Wikimedia, weekly installs from pypistats.org and the npm registry, stars and releases from GitHub, trending models and papers from Hugging Face, and the top AI stories on Hacker News. The agent never writes a number. It picks what mattered this week and writes the notes. A second agent checks each note against its sources and drops anything it can't confirm. A last script checks that every number in the notes matches the data and that every link works, and the page is published only if all of that passes. It has run 2 times so far: 2 published. The last run, on 19 Oct, published.

Page views measure curiosity, not use, and install counts include CI and mirrors, so read both as trends, not user counts. Raw data for this week
