this week

Moonshot AI released open weights for its Kimi K3.1 Pro model, and a new open model turns a single photo into a 3D scene.

  • Kimi K3.1 Pro: open weights for a 2.8-trillion-parameter model

    Moonshot AI published the weights of Kimi K3.1 Pro, which its model card calls an open-weight, multimodal model built for agent tasks such as coding and financial research. It is a mixture-of-experts design (only part of the model runs for each token) with 2.8T total and 104B active parameters, and a 1-million-token context window. The license is a custom Kimi license, not a standard open-source one.

  • Idol turns one image into a 3D Gaussian splat

    Idol is an open model that takes one picture of an object and generates a 3D Gaussian splat (a 3D scene made of many small colored blobs), including sides the picture never showed. The model card says it uses 7.2 GB of GPU memory, runs on consumer GPUs and writes a standard .ply file. It needs access to two gated encoder models and an NVIDIA GPU. The license is Apache 2.0.

how this page is made

A Claude Code job runs every Monday. A script collects the numbers: Wikipedia page views from Wikimedia, weekly installs from pypistats.org and the npm registry, stars and releases from GitHub, trending models and papers from Hugging Face, and the top AI stories on Hacker News. The agent never writes a number. It picks what mattered this week and writes the notes. A second agent checks each note against its sources and drops anything it can't confirm. A last script checks that every number in the notes matches the data and that every link works, and the page is published only if all of that passes. It has run 5 times so far: 5 published. The last run, on 9 Nov, published.

Page views measure curiosity, not use, and install counts include CI and mirrors, so read both as trends, not user counts. Raw data for this week
