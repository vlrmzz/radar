this week

DeepSeek released both a new model and the engine that serves it, Anthropic previewed a background-working agent, and Anthropic's Python SDK installs grew fastest of the big model SDKs.

  • DeepSeek open-sources DeepInfer, the engine behind its own service

    DeepInfer is the inference framework (the software that runs a model to answer requests) that DeepSeek says powers its large-scale production services. The open release supports DeepSeek-V4.1-Flash on NVIDIA SM100 GPUs and Huawei Ascend chips, under the Apache-2.0 license. It leaves out some serving parts, such as a KV cache system and load balancing. It was the most discussed AI story on Hacker News this week.

  • DeepSeek-V4.1-Flash-1017 tops Hugging Face trending

    DeepSeek-V4.1-Flash-1017 is an update to V4.1-Flash. Its model card says it aims at better reasoning, coding, agent and image tasks, with shorter outputs and faster task runs. It accepts text and images and is released under the MIT license. It ranks #1 on Hugging Face trending.

  • Anthropic previews Claude Duet, an agent that works in the background

    Claude Duet is a research preview of an agent that takes a request, works on it in its own cloud environment and reports back. It writes a morning brief and asks before sensitive actions such as sending messages or making payments. The product page says it is powered by Opus 5.5 and is on a waitlist for Pro and Max subscribers in the US.

  • Anthropic SDK installs grow fastest of the big model SDKs

    Installs of the Anthropic Python SDK grew 29%, ahead of the OpenAI SDK at 18% and the Google Gen AI SDK at 12%. The SDK moved to a 2.0 line on 21 October and reached 2.3.0 on 23 October. The 2.0 release adds support for a new API version.

how this page is made

A Claude Code job runs every Monday. A script collects the numbers: Wikipedia page views from Wikimedia, weekly installs from pypistats.org and the npm registry, stars and releases from GitHub, trending models and papers from Hugging Face, and the top AI stories on Hacker News. The agent never writes a number. It picks what mattered this week and writes the notes. A second agent checks each note against its sources and drops anything it can't confirm. A last script checks that every number in the notes matches the data and that every link works, and the page is published only if all of that passes. It has run 3 times so far: 3 published. The last run, on 26 Oct, published.

Page views measure curiosity, not use, and install counts include CI and mirrors, so read both as trends, not user counts. Raw data for this week
